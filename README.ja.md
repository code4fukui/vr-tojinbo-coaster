# vr-tojinbo-coaster

Three.jsとWebXRで構築されたVR（バーチャルリアリティ）ジェットコースター体験です。垂直ループを備えたダイナミックなコースを駆け抜け、速度に応じて変化するリアルな風の環境音を楽しめます。

## デモ

- **[VR東尋坊コースター](https://code4fukui.github.io/vr-tojinbo-coaster/)**

## 特徴

-   **没入型VR体験**: WebXR対応ブラウザとVRヘッドセットを使用して、完全に没入できる3Dの世界に入り込むことができます。
-   **カスタムコースター軌道**: カスタムの `THREE.Curve` クラスを使用して数学的に定義された経路をコースターが走行します。スリル満点の垂直ループと滑らかな軌道のつながりが特徴です。
-   **ダイナミックな風の音**: Web Audio APIの `AudioWorklet` を活用し、コースターの速度に応じてピッチ（音の高さ）と音量が変化するリアルな風の効果音を生成します。
-   **昼夜モード**: 昼と夜の環境を切り替えることができます。VRモードでは、コースターが停止している間に下を向くことで切り替えが可能です。
-   **物理ベースの挙動**: アニメーションループ内でコースターの速度が動的に計算され、下り坂では加速し、上り坂では減速します。
-   **デスクトップおよびVR対応**: デスクトップ環境ではマウスとキーボードで完全に操作でき、VRヘッドセットを使用すればより没入感のある乗車体験が可能です。

## 操作方法

### デスクトップ

| アクション              | 操作        |
| ------------------- | -------------- |
| 周囲を見渡す              | マウス移動 |
| コースターの開始 / 停止 | `Space` キー    |
| 昼夜モードの切り替え    | `N` キー        |

*画面をクリックするとマウスポインターがロックされ、カメラ操作が可能になります。解除するには `Esc` キーを押してください。*

### VRモード

| アクション              | 操作                                     |
| ------------------- | ------------------------------------------- |
| コースターの開始       | VR空間に入ると自動的に開始されます。     |
| 昼夜モードの切り替え    | 停止中に1.5秒間下を向きます。   |

*コースターは1周すると、開始地点で自動的に停止します。*

## 技術概要

-   **`TojinboCoaster.js`**: 垂直ループ部分の複雑なジオメトリや接線計算を含む、コースターの経路を定義しています。
-   **`WindNode.js` & `wind-processor.js`**: 高性能なオーディオ処理を行うカスタム `AudioWorkletNode` を実装しています。`.wav` ファイルをループ再生し、ピッチと音量を調整することで風速をシミュレートします。
-   **`SkyGroundGeometry.js`**: 空を表す球体を生成し、その下半球を平らにして地面を作成するカスタム `BufferGeometry` です。これらを単一のメッシュ内で実現しています。
-   **`models/sleeper.glb`**: 木製の枕木（レール）の3Dモデルで、`GLTFLoader` を使用して読み込まれます。
